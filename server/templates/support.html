アプリについて

「HSK受験者が作った単語帳」は、HSK1〜6級の全単語約5,000語を収録した中国語語彙学習アプリです。無料でダウンロードして今すぐ学習をはじめられます。

文字暗記と音声暗記の2つのモードで、視覚・聴覚の両面から効率よく単語を定着させます。さらに7日間のスプリント機能でパンダスタンプを集めながらゲーム感覚で学習できます。

主な機能

📖

文字暗記モード

漢字・ピンイン・例文を見ながら視覚的に記憶。暗記状況をフィルタリングして効率的に復習できます。

🎧

音声暗記モード

中国語を隠した状態で音声から意味を理解。リスニング力と語彙力を同時に強化します。

🔊

音声再生機能

中国語・日本語・英語の例文を連続再生。0.5〜1.5倍速調整対応。通勤中のながら学習に最適。

🐼

スプリント機能

7日間のスタンプラリー形式で学習を進捗管理。60種類のパンダスタンプを集めながらゲーム感覚で継続できます。

📊

進捗管理

暗記済み・暗記必要・未暗記の3段階で進捗を可視化。HSK各級ごとに独立した進捗管理が可能です。

🔇

広告なし

無料プランも含め、広告は一切表示されません。学習に集中できる環境を提供します。

よくある質問

料金・サブスクリプションについて

無料で使える範囲はどこまでですか？
HSK1級の全150語は完全無料でご利用いただけます。HSK2〜6級は各レベル最初の50語（グループ1）が無料です。50語を超える単語にアクセスするにはプレミアムプランへの登録が必要です。
プレミアムプランの料金は？
月額¥380（税込）です。サブスクリプションはApple App StoreまたはGoogle Playを通じて課金されます。いつでもキャンセル可能で、キャンセル後は当月末まで引き続きご利用いただけます。
サブスクリプションのキャンセル方法は？
iOS（iPhone / iPad）の場合：
  1. 設定アプリ を開く
  2. 画面上部の Apple ID をタップ
  3. 「サブスクリプション」をタップ
  4. 「HSK受験者が作った単語帳」を選択してキャンセル

Androidの場合：
  1. Google Play ストア を開く
  2. 右上のアカウントアイコンをタップ
  3. 「お支払いと定期購入」→「定期購入」をタップ
  4. 「HSK受験者が作った単語帳」を選択してキャンセル

次回請求日の24時間前までにキャンセルすれば、翌月以降の請求は発生しません。
機種変更・再インストール後にプレミアムを復元するには？
アプリ内の「プロフィール」画面にある「購入を復元」ボタンをタップしてください。同じApple IDまたはGoogleアカウントでご購入された場合、自動的にプレミアムが有効になります。
プレミアムを購入したのに反映されない場合は？
以下の手順をお試しください：（1）アプリを一度終了して再起動する、（2）プロフィール画面の「購入を復元」をタップする、（3）端末のインターネット接続を確認する。それでも解決しない場合はお問い合わせください。
無料トライアルはありますか？
現在、無料トライアル期間は設けておりません。ただし、HSK1級の全語とHSK2〜6級各50語は無料でご利用いただけるため、まずは無料でアプリの学習機能をお試しください。

機能・学習方法について

文字暗記と音声暗記の違いは何ですか？
文字暗記モードでは漢字とピンインが表示され、視覚的に単語を覚えます。音声暗記モードでは中国語が隠された状態で音声を聴いて意味を理解する練習ができます。それぞれの暗記状況は独立して管理されます。
インターネット接続は必要ですか？
音声再生にはデバイスのテキスト読み上げ機能（TTS）を使用しているため、基本的にオフラインでもご利用いただけます。サブスクリプションの購入・復元にはインターネット接続が必要です。
学習データを他のデバイスに引き継げますか？
現在、学習データはお使いのデバイス内にのみ保存されます。デバイス間の同期機能は今後のアップデートで検討しています。なお、サブスクリプションは同じApple ID / Googleアカウントで別端末にも復元できます。
学習データをリセットしたい場合は？
アプリ内の「プロフィール」画面から、すべての学習データをリセットできます。リセットすると暗記状況がすべて初期化されますのでご注意ください。サブスクリプションはリセットされません。
どのレベルの単語が収録されていますか？
HSK1〜6級の全単語約5,000語を収録しています。各級ごとに50語単位のグループに分かれており、段階的に学習を進められます。各単語には漢字・ピンイン・日本語訳・例文（中国語・日本語・英語）が含まれます。
